# Antimicrobial Dental Cement Project

## About
This project is based on my MSc dissertation on antimicrobial dental cement.

## Work Done
- Formulated Zinc Phosphate dental cement
- Conducted leaching studies in water and artificial saliva
- Measured pH changes over time
- Performed ICP analysis for ion release
- Used SEM for structural analysis

## Key Findings
- Zinc ion release varies depending on environment
- pH changes influence cement behavior
- Water and saliva show different interaction patterns

## Future Scope
- Long-term stability analysis
- Mechanical strength testing
- Clinical applications
